## 問題紹介 —『Hand-Painted Logo』

### ストーリー

**AtCoder 社の高橋社長**が、**企業対抗リーグのロゴを自分の手でキャンバスに描く**ことにしました。ところが社長は手先が不器用で、**いったん筆を下ろすと、別の色との境目かキャンバスの端に届くまで、まっすぐ塗り続けてしまう** 🎨

### ルール

**N × N のキャンバス**はすべて色 0 から始まり、**目標画像 A** と完全に一致させます。1 回の操作では、

- **始点のマス・方向（上下左右）・色 c を選ぶ**
- 始点の今の色を x として、**始点を c で塗り、次のマスの色が x である限り、その方向にまっすぐ塗り進める**

**同じ色 x が続く限り止まれない**のがこの問題の肝です。**c = x でも 1 回と数えます**。

### 得点

**操作回数を T として N² − T + 1 点**。**少ない筆数で描くほど高得点**で、**100 ケースの合計**が提出スコアです。**目標と 1 マスでも違えば WA** なので、**「必ず完成させる」うえで手数を減らす**問題でした。

## 解法 — ビームサーチ、焼きなまし、区間 DP

**「正しい色のマス数」を評価にした貪欲・ビームサーチ**が、多くの上位の出発点でした。

{{< twitter user="Jinapetto" id="2123765331110044010" >}}

> **第三戦 Open 5 位 色が合っているマスの数をスコアにして貪欲するとそこそこ良い 愚直なビムサに載せると幅 200 ぐらいは回る**

**αβ は「正しい境界線の個数」も評価に加えている**のがポイントです。**「止まれない筆」では、色の境目がそろっていることが次の一筆の止まり位置を決める**ので、**境界を評価するのは理にかなっています**。

**もう一つの流れが「外側から完成させる区間 DP」**でした。**てんぷら さん**（オープン 7 位 ✨️🍤✨️🍤✨️）：

{{< twitter user="tempuracpp" id="2123768290908713464" >}}

> **dp[l][r][u][d] = [l, r] \* [u,d] の外側が全部完成しているときの内側を埋めるための手数 として、どこか 1 行 or 1 列を完成させて次に行く区間 DP**

**物理好き さん** も **「dp[u][d][l][r] = {内側を 0、外側を完成形とみなした最小手数} みたいな DP をしたかったが、合わず」** と同じ方向を考えていました。**koi さん** は **「時間がなく 1 時間だけ参加 17 位 行、列ごとに貪欲にやる 順番を雑山登り」**。
