## A『急増する細菌』— 2 日前に続いて「long 型」

**1 日目に A 匹、毎日 2 倍になる細菌の数を N 日分出力**。**N ≤ 30、A ≤ 10^9** なので、**30 日目は A × 2^29 ≈ 5 × 10^17** — **32 ビット整数には到底収まりません**。

**春の七草 さん** の一言がすべてです：**「A long 型使おうね (1 敗)」** 🦠

[2 日前の AWC0192 の A](/atoco-cp/post/2026-11-03-awc0192/)（降水量の等差数列）でも **「int じゃなくて ll でやりましょうね」** という声があったばかり。**YTOK\_cp さん** の **「既視感👁️」**が、まさにそれを言い当てています。

**とーらす さん** の **`iterate ( * 2 ) a`**、**☆ありゅ☆ さん** の **`print(*[A<<n for n in range(N)], sep="\n")`**（ビットシフトで 2 倍）と、**一行の書き方**もいろいろでした。

## B『花園の列』— 花が 0 個なら 1

**花がいちばん多く咲いている列（同じなら最も左）を答える**。**ペナ 40** の理由も、**春の七草 さん** が教えてくれています：**「B 花が一個もない時 0 じゃなくて 1 よ (1 敗)」** 🌼

**どの列にも花がなければ、全部の列が「0 本で同数」なので、答えは最も左の 1 列目**。**最大値の初期値を 0 にして「より大きいとき更新」にすると、更新が一度も起きずに 0 を出力してしまう**わけです。

**とーらす さん** は **「transpose して [ 1 .. ] と zip して maximumOn」**、**☆ありゅ☆ さん** は **`data.index(max(data)) + 1`**、**YTOK\_cp さん** は **「列番号ごとに 'F' の出現をカウントして argmax」**。**「最大値の最初の位置」を返す関数**を使えば、自然と 1 になります。

**yamate11 さん**：**「要求の高い客から順に，要求を満たす商品で残っているもののうち，一番高いものを売る」**、**とーらす さん**：**「C を降順に見て売れるようになったやつらの価格を multiset に」**、**YTOK\_cp さん**：**「(A\_i, B\_i) を降順ソートしたものを MaxHeap に突っ込む 既視感👁️」**。こちらも [AWC0192 の D](/atoco-cp/post/2026-11-03-awc0192/)（難易度順に見て上位 K 問をヒープで保つ）に似た形でした 💻

## E『鉄道旅行』— 所持金を持つ Dijkstra

**普通列車か特急列車かを毎回選び、運賃の合計を K 円以下に抑えて、所要時間を最小化**。**K ≤ 1000** なので、**「(都市, 使った金額)」を頂点にした Dijkstra** が定石です。

**とーらす さん**：**「( 場所, 金額 ) を頂点にして Dijkstra」**、**☆ありゅ☆ さん**：**「(ノード番号, 運賃) をノードとし時間を距離とする Dijkstra」**、**ぴよ さん**：**「頂点を K 倍化してダイクストラ法」**。

**yamate11 さん** は一工夫しています：**「頂点 (floor(K/2) + 1) 倍化ダイクストラ」** — **運賃は 2 人分で 2 倍**なので、**1 人あたりの金額で持てば状態数は半分**で済むわけですね 🚃
