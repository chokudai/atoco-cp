## あとこの所感

AWC0160 は **「A 最高最低を除く + B 最大部分和 + C スタミナ DP + D 昇降順 2 本管理 + E 単調スタック」** の 5 問構成。参加者 **176 名**。

今夜のテーマは **道具の使いどころ**だったと思います。それを一人で言い切ってしまったのが **ぴよ さん**でした。

> **Ｂ：セグ木をつかいそうになったが、問題Ｂだったのでやめることにした。セグ木に負けるところだった。**
> **Ｄ：セグ木を使った。Ｄ問題だから許されるだろう。**

**同じ道具を、B では退け、D では採用する**。その判断基準が **「問題番号」** というのが実に競プロらしいです 😄 **B は累積和で足りる、D はデータ構造が要る** — **結果的にこの見立ては正しかった**わけで、**「セグ木に負ける」という言い方**には、**簡単な問題に重い道具を使ってしまう自分への戒め**が込められているように思います。

そして **同じ構図が E でも起きていました**。**ありゅ さんの「WaveletMatrix で出そうとして無事死亡」「各色に対して配列作って二分探索でいいじゃん…orz」**、そして **のりかめ さんの「スタックを使って綺麗に書けた」**。**同じ問題を、Wavelet Matrix と Treap とスタックが並んでいる**のです。**どれも正しいけれど、軽い道具で足りるなら軽いほうが速い**、という当たり前のことが、そのまま順位に効いていました 🔧

**C と D のペナ差（34 対 9）** も、この線で説明できそうです。**C は「遷移の条件を正しく弾く」という、道具ではなく詰めの問題**でした。**yamate11 さんの「言われたとおりに DP を書いたつもりなんだけどなあ」** が象徴的で、**書けてしまうから提出して落ちる**。対する **D は「昇順と降順を 2 本持てばいい」と分かれば道具は何でもよく**、**気づくまでは提出しない**。[AWC0158 で見た「転ぶのが提出の後か前か」という構図](/atoco-cp/post/2026-09-16-awc0158/) が、ここでも繰り返されていました。

最後に **B が [AWC0158 の B](/atoco-cp/post/2026-09-16-awc0158/) とほぼ同じ問題**だったこと。**ありゅ さんの「B. AWC0158B」** という身も蓋もない一言と、**Tanaka.A さんの「幅 0 は除外の教訓が生きた」** が対になっていて良かったです。**二週間前に踏んだ地雷を覚えている人が、今夜は速かった** — それもまた実力のうちですね 🌸
