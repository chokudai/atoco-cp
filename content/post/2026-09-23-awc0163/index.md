## A『応援要請』— 切り上げ除算とオーバーフロー

**AC 率 66%、ペナ 28**。**「各要請に必要な回数を切り上げ除算で求めて合計し、M を引く」** でした。

**よには さん** が身も蓋もなくまとめています：

{{< twitter user="yoniha428" id="2102732221346136125" >}}

> #AWC0163 ABCD 36 分 1 ペナ **A ゴチャゴチャ書いてあるが max(0,sum(ceil(Ai/K))-M)** B ans<=64 なので while **C ギャグ、N-2** D DP[高店舗数][青店舗数][高金額][青金額] としたくなるが、後ろ 2 つは高金額-青金額+60 を持てば十分で、これで間に合うらしい 次元が多い DP を出して 1 ペナ **E AI 専用問題**

**「ゴチャゴチャ書いてあるが max(0,sum(ceil(Ai/K))-M)」** — **問題文の装飾を剥がすと一行**、というやつですね 😄

**Tanaka.A さん**：**「A max(必要回数-M,0)」**、**YTOK\_cp さん**：**「A: max(Σceil(A\_i/K)-M,0)」**、**ほっしー さん**：**「A: div\_ceil して saturating\_sub」**

ただ **ペナ 28** が出ています。**秋ナス さん** が原因を挙げてくれました：

{{< twitter user="akinasu_aki" id="2102731943553159578" >}}

> #AWC0163 3 完 **A div\_ceil またオーバーフローで 1 ペナ、分かんないなら全部 long でいいよ** B while(L>W) div\_ceil(L,2) **C 流石にギャグ gcd は広義単調減少するからペアが最善で答えは N-2** DはDPのD、クエリごとに毎回解くだけではある(解けず) **E は流石に難しすぎる**

## あとこの所感

AWC0163 は **「A 切り上げ除算 + B 半分にし続ける + C ギャグ + D 差分 DP + E 空間探索」** の 5 問構成。参加者 **213 名**。

今夜の順位表は **見事な二段構え**でした。**A・B・C が 66%・65%・59% と横並びで、3 完 83 名という大きな山**を作り、**D で 18%、E で 2 名**と落ちる。**「3 完までは全員、そこから先は別世界」** という設計です。

面白いのは、**その 3 問の体感難易度が問題番号と逆だった**こと。**ほっしー さんの「体感難易度 C<B<A」** が象徴的で、**A のペナ 28 に対して C はペナ 10**。**最後の C がいちばん軽かった**わけですね。

**C は「ギャグ」「出オチ担当」「AWC 名物」** と呼ばれた問題でした。**答えが N-2**、しかも **とーらす さんいわく「A は読み込まなくてよい」**。**入力を一切見ずに答えが出る**という極端さです 😄 一方で **Tanaka.A さんが「G を求める直前まで実装してしまった」** ように、**真面目に解こうとすると回り道になる**のもこの種の問題らしいところでした。

**D で分かれたのは「確信」だったように思います。** **とーらす さんは「毎回やって間に合う」と書き**、**よには さんは「これで間に合うらしい」と書いた**。対して **yamate11 さんは「計算量が不明でパスを選択」**。**同じ「差分を持てば範囲が狭い」という観察に届いていても、そこから踏み出せるかどうか**が 39 名の線引きになっていました 🔍

そして **E の AC 2 名**。**ほっしー さんの「正解者 2 名ってどういうこと」**、**よには さんの「AI 専用問題」** という評に、この壁の高さが出ています。**yamate11 さんが「訪問済みを削除しながら BFS」という正着に近い方針を立てながら実装が間に合わなかった**ことも含めて、**方針と実装の距離が遠い問題**だったのでしょう。

**秋ナス さんの「分かんないなら全部 long でいいよ」** が、[昨夜の「値の範囲に自信がないなら INF<long> にしましょう」](/atoco-cp/post/2026-09-22-awc0162/) と**二夜連続の教訓**になっていたのも、ちょっと笑ってしまいました 😄 オーバーフローは本当に何度でも来ますね。
