## D『整数面積の三角形』— AC 19、E より難しい

**AC 率 9%（19 名）、ペナ 6**。**今夜の実質的な最難関**です。

**「N 個の点から 3 点を選んで、面積が整数になる三角形を数える」** という幾何の数え上げでした。

**秋ナス さん の「D N^3 から早くする方法が分からず」** — **3 点の全組み合わせは O(N^3)**、そこから落とすのが本題です。

**うにだよ さん** が解法を詳しく書かれています：

> **D:三角形の面積は 1/2(ad-bc) なので、原点にする点 N 個全探索で、(a,b)=(偶 or 奇,偶 or 奇) の個数を数えて、ad-bc=偶数になる数を計算する**

**面積は 1/2 × |行列式|** なので、**行列式が偶数なら面積は整数**。そして **行列式の偶奇は、座標の偶奇だけで決まる**。だから **座標を (偶,偶)/(偶,奇)/(奇,偶)/(奇,奇) の 4 種類に分類して数えれば O(N^2)** に落ちる、というわけです 🔺

ただし **もう一つの罠**がありました：

> **一直線上に並んでるとき、ad=bc だから、a/b=c/d で、a/b が等しいものの数を数えればわかる**

**3 点が一直線上にあると面積は 0** — **三角形にならない**ので除外する必要がある。**傾きが等しい点を数えて引く**わけですね。

**𡆢 さん** も同じ二段構え：

{{< twitter user="0x3b800001" id="2105992343778447479" >}}

> #AWC0170 お疲れ様でした A ✓ B ✓ C ✓ ソートして後ろから sum%N 人は +1 **D ✓ 2 点選んで残りの 1 点の座標の偶奇, 直線ごとに点を数える** **E ✗ 間に合わんかった……行列累乗**

**「座標の偶奇」と「直線ごとに点を数える」** — この 2 つが揃ってはじめて通る問題でした。

**ありゅ さん** は方針まで到達していました：

{{< twitter user="Fo_Tr0" id="2105992637333586311" >}}

> #AWC0170 ABC の 3 完　**最近問題と相性が悪い（ぇ** A. 逐次的に計算 B. sum(A) を N で割った床と余りを計算して A をソートして +1 されたものを決めて計算 C. わからないけど set 使って全部試せばいいじゃんしたら通った **D. det\neq 0 かつ det が偶数のものを選べばいいんだろうけど実装できなかった** E. 見てない

**「det ≠ 0 かつ det が偶数」** — **一直線上でない（det ≠ 0）かつ面積が整数（det が偶数）**。**条件は完璧に言い当てている**のに、**それを O(N^2) で数える実装**に届かなかった、と。**「最近問題と相性が悪い（ぇ」** の自己評価が切ないです 😢

今夜は **2 つの「並び替わり」** がありました。

**ひとつは D と E**。**D が AC 19、E が AC 27**。**問題番号の順と難易度の順が逆転**しています。理由ははっきりしていて、**D は「偶奇で分類」と「一直線を除く」の二段構えが要る幾何の数え上げ**、**E は「行列累乗」と見抜ければ定番の実装**。**同じ「難しい」でも、気づきが 1 つで済むか 2 つ要るか**の差でした 🔺
