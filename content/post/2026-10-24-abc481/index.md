## B『Polyline』— 「A〜D で 1 番むずい」

**点 (i, A\_i) を順に結んだ折れ線と、直線 y = K の交点の数**を数える問題。**ペナ 3486** です。

**ポイントは「端点ちょうどの場合」**。**頂点がちょうど y = K にあると、隣り合う 2 本の線分で同じ点を 2 回数えてしまう**。**横に寝た線分（A\_i = A\_{i+1} = K）**も扱いが必要です。

**yu\_w(ゆ) さん** の **「ぴたり賞は別計算」**、**GOT かこけい さん** の **「小 < K < 大なら +1、A\_i = K なら +1」** — **「挟む」と「ちょうど」を分けて数える**のが定石でした。**𡆢 さん** は **「K が y1, y2 の間なら x 座標を set に追加」** と、**重複を set で消す**方法です。

## D『Autopilot』— 燃料 0 と 1

**「番号最小の行き先へは燃料 0、好きな行き先へは燃料 1」**で移動して、**S から T への最小燃料**を求める。**辺の重みが 0 か 1 なので 0-1 BFS**、あるいは **Dijkstra** で解けます。
