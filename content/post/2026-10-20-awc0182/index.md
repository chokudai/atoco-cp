## A〜C

**A は天秤**。重い方の皿が下がるので、**Left・Right・Balanced** を出力します。**𡆢 さん** は Ruby の宇宙船演算子で **`%w(Balanced Left Right)[A <=> B]`** と一行に。**`<=>` が -1・0・1 を返すのを、配列の添字（-1 は末尾）に使う**、という技ありの書き方です ⚖️

**B は「最初から正解し続けている間だけ o」**。**一度間違えたら、あとは全部 x** です。**ペナ 56** は、**☆ありゅ☆ さん** の **「問題文斜め読みした結果 1 ペナ」** が答えでしょう。**「一度間違えると、その問題以降はたとえ正解しても得点はもらえない」**を読み落とすと WA になります。**amesyu さん** の **「0 問目を追加した」**、**𡆢 さん** の **`p *= A; "xo"[p]`**（掛け算で「一度 0 になったら 0 のまま」）と、工夫もいろいろでした。

**C は「満足度の高い順に、在庫の範囲でちょうど K 個買う」貪欲**。**合計 K 個に届かなければ -1**。**yamate11 さん**：**「B の大きい順に和が K になるまで買う」**、**Tanaka.A さん**：**「B の降順に並べて貪欲。K が余ったら -1」**。

## E『荷物の集積作業』— 遅延セグ木か、set か

**区間 [L, R] 内の荷物を、両端の倉庫のうち近い方へ全部集める。その費用を答える作業を Q 回**。**荷物は実際に移動する**ので、以後の作業は移動後の配置で行います。

ここで **解き方がきれいに二つに分かれました**。

**① 遅延セグ木派**。**Tanaka.A さん**：**「3 本の遅延セグ木で A, i\*A, (N-i-1)\*A を管理」** — **個数と、位置で重み付けした個数**を区間和で取れれば、**距離の合計が計算できる**というわけです。**amesyu さん** は：

**「こね」が 14 回** 😂 **遅延セグ木 3 本をこねる大変さ**が、文字数で伝わってきます。**うにだよ さん**・**☆ありゅ☆ さん**（**「セグ木を 2 本用意してワチャワチャ」**）も、こちらの道でした。

**② set で愚直に派**。ここで効いてくる観察が **「荷物のある倉庫は減る一方」**です。**1 回の作業で荷物は両端の 2 か所に集まる**ので、**荷物のある倉庫の数は、作業のたびに増えても 2 か所まで**。

**「移動対象となる位置の総和は N + 2Q しかない」** — **荷物のある倉庫だけを set に入れておき、区間内のものを取り出して両端に集めるだけ**。**一度取り出した倉庫は空になる**ので、**全体の手間は N + 2Q 程度**に収まります（いわゆる「償却」の考え方です）。

そして **両方を知った人たちの感想**が面白いところです。**𡆢 さん** は遅延セグ木で解いたあとで **「償却すればふつうのセグ木でもいけるのね……」**、**kwm\_t さん** は **「E を遅セグでやってすまないの札」** 🙇 **重装備で通したあとに、軽い道があったと知る** — AWC らしい風景ですね。
